# солик) розыгрыши — @RandomSolikBot

Бот честных розыгрышей в каналах и чатах в стиле Solutions. Идею взяли у
[RisenSky/RandomGodBot](https://github.com/RisenSky/RandomGodBot), код написан
с нуля на aiogram 3: в оригинале не работала проверка подписки, победители
могли повторяться, а таймер итогов умирал после первой ошибки.

## Что умеет

- Канал добавляется кнопкой «добавить канал»: Telegram сам предлагает выбрать
  канал и выдать боту права. Можно и руками — бот замечет, что его сделали админом.
- Мастер из 6 шагов: канал, пост (текст / фото / видео / гифка / файл),
  победители, обязательные подписки (до 5), время публикации, время итогов.
  Потом предпросмотр.
- Пост с кнопкой «участвовать · N». Подписки проверяются при входе и ещё раз
  на финише: отписавшегося победителя заменяет следующий по очереди.
- Итоги выходят карточкой с соликом ответом на пост. Кнопка поста ведёт на
  итоги. Победителям и владельцу приходит сообщение.
- «Мои розыгрыши»: опубликовать или отменить раньше времени, подвести итоги
  сейчас, выгрузить участников, добавить победителя.
- Честность: в посте стоит sha256 секретного сида, в итогах сид раскрывается.
  `/check N` сверяет сид и показывает код, по которому любой пересчитает
  победителей сам (`draw.py`).

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env   # вписать BOT_TOKEN
python main.py           # или run.bat
```

## Проверка

```bash
python selfcheck.py         # таймер, участие, итоги, сбои → «Всё в порядке»
python selfcheck_wizard.py  # мастер и меню через Dispatcher → «Мастер в порядке»
```

## Файлы

| файл | что внутри |
|---|---|
| `main.py` | запуск, таймер, поллинг |
| `wizard.py` | мастер создания |
| `handlers.py` | меню, каналы, мои розыгрыши, кнопка участия, /check, /stats |
| `giveaways.py` | публикация, участие, счётчик, итоги, доп. победитель |
| `draw.py` | честный выбор победителей |
| `texts.py` | все тексты голосом солика, разбор времени |
| `card.py` | баннер /start и карточка итогов |
| `icons.py` | премиум-эмодзи пака Solutions с откатом на обычные |
